# flipFISH
Performs barcode-decoding quality control for FISH-based spatial transcriptomic runs.

It's been known since the introduction of MERFISH that long barcodes, i.e., those more than twenty bits, can be expected to have around half of spots decoded as the wrong mRNA species [(Moffitt and Zhuang 2016)](https://doi.org/10.1016/bs.mie.2016.03.020).
